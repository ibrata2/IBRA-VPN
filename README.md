# IBRA VPN

تطبيق ويندوز يفتح المواقع والتطبيقات المحجوبة (مثل تليكرام).
برمجة وتطوير **ابراهيم الخزرجي** — تليكرام [ibraprogram](https://t.me/ibraprogram) · تيك توك [ibraprogram](https://www.tiktok.com/@ibraprogram)

## المميزات
- **ثلاث طرق اتصال**
  - **سيرفراتي**: VLESS (Reality / Vision) · VMess · Trojan · Shadowsocks · Hysteria2 · TUIC · SOCKS5 · HTTP، وروابط بروكسي تليكرام `tg://socks` و `t.me/socks`، والاشتراكات (Subscription)
  - **WARP مجاني**: سيرفر Cloudflare المجاني، يتسجل تلقائياً بدون حساب
  - **كسر الحجب بدون سيرفر**: تقطيع TLS + DNS مشفّر ضد الحجب المعتمد على اسم الموقع
- **وضعين**: بروكسي النظام (بدون صلاحيات) أو **كل الجهاز** (TUN، يحتاج مسؤول) — يشمل تليكرام وكل البرامج
- **توجيه ذكي**: المواقع العراقية تروح مباشرة والباقي عبر السيرفر
- حظر الإعلانات، DNS مشفّر (Cloudflare / Google / Quad9 / AdGuard)
- فحص سرعة حقيقي لكل السيرفرات، ترتيب، اختيار الأسرع، حذف المعطلة
- عرض IP والدولة بعد الاتصال، سرعة التنزيل والرفع، مؤقت
- أيقونة بجانب الساعة، تشغيل مع الويندوز، اتصال تلقائي
- عربي / English، ثيمات: ذهبي، أحمر، فاتح، حسب النظام
- تحديث تلقائي من داخل التطبيق
- روابط MTProto (`tg://proxy`) تنفتح مباشرة داخل تليكرام
